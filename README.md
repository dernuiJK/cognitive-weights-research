# Cognitive Weights

Independent experimental research on learning, remembering, and revising understanding.

## Independent research overview

Cognitive Weights is an ongoing, self-funded research project led by the independent researcher behind [@dernuiJK](https://github.com/dernuiJK). The long-term question is simple: can a learning system retain useful experience, reconsider what it believes when new information arrives, and use what it has learned in later tasks?

This repository is a plain-language public introduction, not a software or model release.

### Research questions

- Can something learned earlier remain useful in a later interaction?
- Can a correction change the relevant understanding without erasing unrelated learning?
- Can the system seek more information when what it knows is insufficient?
- Can learning affect what it does next, rather than only the answer it gives?
- Do abilities observed separately still work when used together and with less external assistance?

These are research questions, not claims that the corresponding general capabilities have been achieved.

### Progress note — September 19, 2026

Internal experiments have produced encouraging results on selected, narrowly defined learning tasks. Some of these abilities have also been tested as part of longer tasks involving information gathering, decisions, and subsequent feedback.

The important next question is how much of that progress survives when tasks become broader and external help is reduced. This remains under investigation. Success in a small controlled setting does not establish reliable performance in an unfamiliar real-world situation, and separately successful abilities do not automatically make a successful combined system.

This note summarizes project-reported progress. It does not publish the methods or underlying records needed for independent reproduction, and should not be treated as independently verified evidence.

### What remains unresolved

- How well learning transfers beyond the situations used in the experiments.
- How reliably different abilities work together over longer interactions.
- How much external help is still needed.
- How to learn new things while retaining useful earlier learning.

The project does not claim general intelligence, unrestricted continual learning, open-world reliability, or a finished product. Current observations do not establish that its approach is unique, necessary, or superior to other approaches.

## 中文研究简介

Cognitive Weights 是由 [@dernuiJK](https://github.com/dernuiJK) 主导、自费开展的独立实验研究项目。我们长期想回答的是：一个学习系统能否保留有用的经历，在新信息到来时重新考虑原来的认识，并把学到的东西用于后续任务？

本仓库是通俗的公开简介，不是软件或模型发布仓库。

### 我们在研究什么

- 以前学到的东西，能否在后来的交互中继续发挥作用？
- 纠正一项认识时，能否保留其他没有受到影响的学习内容？
- 已知信息不够时，系统能否进一步获取信息？
- 学习能否改变接下来怎么做，而不只是改变怎么回答？
- 分别成立的能力，结合起来、减少外部帮助之后，是否仍然有效？

这些是研究问题，不代表对应的通用能力已经实现。

### 阶段进展：2026 年 9 月 19 日

在部分范围明确的小型学习任务中，内部实验已经获得了一些积极结果。其中一部分能力，也已放入包含获取信息、作出选择和接收反馈的较长任务中进行测试。

接下来更重要的问题是：任务范围扩大、外部帮助减少以后，这些进展还能保留多少？这仍在研究中。小环境里成功，不等于面对陌生的现实情境也可靠；几项能力分别成功，也不等于结合起来就一定成功。

这里仅概述项目内部报告的进展，没有公开供外部独立复现所需的方法和原始记录，因此不应将本简介当作已获独立验证的证据。

### 仍未解决的问题

- 学到的东西能否用于实验范围以外的情境。
- 多种能力能否在较长的交互中可靠地共同发挥作用。
- 系统还需要多少外部帮助。
- 如何在学习新内容的同时，保留有用的旧知识。

项目不宣称已经实现通用智能、不受限制的持续学习、开放世界可靠性或成品系统。现有观察也不能证明采用的方法具有独创性、不可替代性或普遍优越性。
